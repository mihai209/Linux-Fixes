# Contributing

Thank you for helping improve Linux Fixes!

## Before submitting

1. Search existing documentation to avoid duplicates.
2. Describe the affected distribution and relevant versions.
3. Include exact commands and relevant error output where possible.
4. Explain what each command changes and whether it needs sudo.
5. Separate confirmed facts from hypotheses.
6. State whether the solution was tested and on which setup.
7. Remove personal or sensitive information from logs.

## Writing a guide

Use `templates/problem-template.md`.

Prefer safe, reversible troubleshooting steps. Do not recommend disabling security controls, changing broad permissions, or deleting system files unless there is a clear, justified reason and the risks are explained.

## Pull requests

- Use a descriptive title.
- Keep one issue or closely related set of issues per document.
- Add each document to `INDEX.md`.
- Do not claim a fix is verified unless it was actually tested.
